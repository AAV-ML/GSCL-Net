# GSCL-Net

GSCL-Net combines a GATv2 graph branch and a BiLSTM sequence branch for protein production regression.

## Data and Embeddings

The sequences and production labels in `data/Production.csv` are derived from the
dataset reported in the following paper:

> Nature Communications, DOI: https://doi.org/10.1038/s41467-024-50555-y

This dataset is third-party research data and is not original data generated by
GSCL-Net. Before redistributing `data/Production.csv`, check the source paper's
data-availability statement and applicable publisher terms. If redistribution is
not permitted, distribute the code and provide instructions for obtaining the
data from the original source instead.

The file `embeddings/esm2_features_aligned.pt` contains precomputed per-residue
ESM-2 embeddings aligned to the rows and amino-acid positions in
`data/Production.csv`. The embeddings were generated with
`esm2_t12_35M_UR50D`, whose per-residue representation is 480-dimensional.
The bundled tensor has shape `(59549, 7, 480)`, and `config.py` uses
`ESM_DIM = 480` accordingly. The ESM-2 release, preprocessing, alignment rule,
and feature-generation procedure should be retained with the repository for
reproducibility.

## Project layout

- `train.py`: executable training and evaluation entry point
- `config.py`: model, feature, and training configuration
- `data_utils.py`: sequence features and dataset construction
- `models.py`: GNN and BiLSTM model definitions
- `training.py`: training loop, prediction, and metrics
- `plotting.py`: prediction visualization
- `data/Production.csv`: input table
- `embeddings/esm2_features_aligned.pt`: local ESM embeddings file, excluded from Git because of its size
- `requirements.txt`: Python dependencies

## Run

```bash
python train.py
```

The script writes model checkpoints, metrics, and the ensemble scatter plot to the project directory.

## Embeddings

The ESM-2 tensor is approximately 763 MB and is intentionally excluded from
the Git repository. Download or obtain it from the project's data archive and
place it at:

```text
embeddings/esm2_features_aligned.pt
```

The tensor must have shape `(59549, 7, 480)` and must use the same row order as
`data/converted.csv`. The encoder is `esm2_t12_35M_UR50D`.
